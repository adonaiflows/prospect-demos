# Prospect concept demos

Five one-page concept sites for local wellness businesses with weak or missing websites. Each folder is a standalone Next.js app (App Router, TypeScript, Tailwind). None is an official site; all are `noindex`.

| Folder | Business | City |
|---|---|---|
| `unwind-yoga` | Unwind Yoga | Albuquerque |
| `whispering-bean` | Whispering Bean Coffee Roasters | Albuquerque + Rio Rancho |
| `rock-star-coffee` | Rock Star Coffee Company | Rio Rancho |
| `santosha-skin` | Santosha Skin Holistic + Integrative | Albuquerque |
| `mocha-mudd` | Mocha Mudd | Rio Rancho |

Content for each lives in `<folder>/lib/site.ts`. Facts come from public sources only; anything the owner must supply is marked `TODO`.

## Deploy on Vercel
For each folder: vercel.com/new, import this repo, set **Root Directory** to the folder name, deploy.
